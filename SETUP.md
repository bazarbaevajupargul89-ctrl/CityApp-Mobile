# ReelFlow - Complete Setup Guide\n\n## Prerequisites\n- Node.js (https://nodejs.org)\n- npm or yarn\n- Expo CLI (npx expo)\n- Firebase account (https://firebase.google.com)\n\n## Installation\n\n```bash\n# Clone repo\ngit clone https://github.com/bazarbaevajupargul89-ctrl/CityApp-Mobile.git\ncd CityApp-Mobile\n\n# Install dependencies\nnpm install\n\n# or with yarn\nyarn install\n```\n\n## Firebase Setup\n\n1. Go to https://firebase.google.com\n2. Create new project\n3. Add web app\n4. Copy config to `src/firebase.js`\n\n## Running the App\n\n```bash\n# Start development server\nnpm start\n\n# or\nnpx expo start\n```\n\n### On Phone\n- Download Expo Go (App Store / Play Store)\n- Scan QR code\n- App opens on your phone\n\n### On Android Emulator\n```bash\nnpm run android\n```\n\n### On iOS Simulator\n```bash\nnpm run ios\n```\n\n## Building for Production\n\n### EAS Build Setup\n```bash\nnpm install -g eas-cli\neas login\n```\n\n### Build for iOS\n```bash\neas build --platform ios\n```\n\n### Build for Android\n```bash\neas build --platform android\n```\n\n### Submit to App Stores\n```bash\neas submit\n```\n\n## Project Structure\n\n```\nreelflow/\n├── App.js\n├── app.json\n├── babel.config.js\n├── package.json\n├── SETUP.md\n├── screens/\n│   ├── HomeScreen.js\n│   ├── DiscoverScreen.js\n│   ├── CreateScreen.js\n│   ├── ProfileScreen.js\n│   └── AuthScreen.js\n├── src/\n│   ├── locales.js\n│   ├── firebase.js\n│   ├── services/\n│   │   ├── auth.js\n│   │   ├── upload.js\n│   │   └── api.js\n│   └── data/\n│       └── reels.js\n└── README.md\n```\n\n## Troubleshooting\n\n### Clear cache\n```bash\nnpm start -- --clear\n```\n\n### Reinstall dependencies\n```bash\nrm -rf node_modules\nnpm install\n```\n\n### Port already in use\n```bash\nnpm start -- --tunnel\n```\n\n## Features\n- ✅ Reels feed\n- ✅ Discover page\n- ✅ Create Reels\n- ✅ User profile\n- ✅ Firebase auth\n- ✅ Video upload\n- ✅ Likes/comments\n- ✅ 3 languages (ru/kk/en)\n\n## Support\nFor issues, create an issue on GitHub.\n"
